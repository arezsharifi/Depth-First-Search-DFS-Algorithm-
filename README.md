# Depth-First Search (DFS) Algorithm 🕸️

A simple, recursive implementation of the Depth-First Search (DFS) algorithm in Python. 

This repository contains a Python script that demonstrates how to traverse a graph using DFS to find a specific goal node.

## 📖 What is DFS?
Depth-First Search is an algorithm for traversing or searching tree or graph data structures. The algorithm starts at the root node and explores as far as possible along each branch before backtracking.

## 📂 Repository Structure
- `dfs_search.py`: The main Python script containing the algorithm and a test case.
- `README.md`: Documentation for the project.
